## 一、这是什么

**dsh-airbag（AI 安全气囊）**：DSH 的非侵入式安全护栏插件。拦截粘贴/写入给 Agent 的 API 密钥、追踪泄露事件、检测审批盲批与疲劳、提供工作区安全体检。所有通知走右下角边角浮层，绝不抢焦点、不打断输入。

完整需求文档：`dsh-airbag-prd.md`（仓库根目录，可删改的产品需求文档）

## 三、已实现功能（v0.1 → v0.4.2）

| 版本 | 功能 | 状态 |
|---|---|---|
| v0.1 | A1 粘贴拦截（阻止/脱敏/警告三档）、G1 边角通知中心（L0-L4 四级 + 聚合 + 勿扰）、G6 首次安全体检、规则引擎（45+ 密钥模式） | ✅ 完成 |
| v0.2 | A2 写入拦截（`write`/`edit`/`bash`/`run_code` 参数扫描 → deny 或转原生审批） | ✅ 完成 |
| v0.3 | B 审批疲劳洞察（盲批检测 <2s、疲劳指数 30 分钟密集批准、纯观察者不决策） | ✅ 完成 |
| v0.4 | **修复** composer 选择器（真实 DOM `data-composer-card`）、**删除演示模式**、修复配置外部编辑不感知 | ✅ 完成 |
| v0.4.1 | **安全加固**：宿主监听器 fail-open（airbag 自身任何异常都不影响工具调用与审批链，事件记录失败不吞拦截决策）；客户端 body 未就绪时延迟挂载、localStorage 不可用时静默降级 | ✅ 完成 |
| v0.4.2 | **修复 A1 粘贴拦截失效**：DSH composer 是 React 受控 textarea，其自身 `onPaste` 手动读剪贴板插入文本、不理会 `defaultPrevented`；改为 capture 阶段 `preventDefault()` + `stopPropagation()` 截断事件传播（React 委托层收不到事件），并加防御性内容清洗 `scrubComposer` | ✅ 完成 |

## 四、如何使用

```sh
# 安装（重装到其他机器时）
dsh plugin --profile web add ./dsh-airbag-0.4.2.tgz
# 或 npm 发布后：
dsh plugin --profile web add dsh-airbag
# 重启后生效
```

1. 重启 DSH Web（3080 端口）
2. 右下角出现 🛡️ **Airbag** 按钮
3. 粘贴密钥 → 被阻止 + 右下角 toast
4. 点 🛡️ → 面板：拦截记录 / 体检（输入路径扫描）/ 设置（处置档、通知级别、白名单、自定义规则）

### 重启后请验证

1. 粘贴一个真实格式的 API 密钥（`sk-` 开头的 DeepSeek Key，或测试夹具中的示例值） → 应被阻止（设置默认"阻止粘贴"）
2. 让 agent 执行 `echo <示例密钥> > x.txt` → 写入被 deny
3. 快速连点 3 次审批（<2s）→ 出现"盲批检测"提示
4. 面板应只有 记录 / 体检 / 设置 三个 tab（演示已删）
